# Vanilla JavaScript Style Guide

- Use TypeScript ES modules compiled for browser use; no UI framework.
- Use 2-space indentation, semicolons, strict equality, and descriptive names.
- Prefer named exports, small pure functions, and explicit DOM boundaries.
- Keep event handlers thin; dispatch typed commands to application services.
- Do not use `eval`, dynamic code execution, or global mutable state.
- Add JSDoc to public JavaScript APIs and TypeScript types to domain contracts.
